# Webzio News Search Tool

> Search global news with [Webz.io](https://webz.io), the contextual news search API. Get token-efficient article excerpts with titles, URLs, and metadata.

The `WebzioNewsSearchTool` lets CrewAI agents search news and current events using [Webz.io News Search](https://docs.webz.io/docs/webz/news-search-api-mcp). It returns the most relevant articles for any query, with rich filters loaded live from the hosted MCP server.

## Installation

Install the CrewAI tools package with MCP support:

```shell
pip install 'crewai[tools]'
```

## Environment Variables

Set your Webz API token as an environment variable:

```bash
export WEBZ_API_TOKEN='your_webz_api_token'
```

<Note>
  The environment variable name is `WEBZ_API_TOKEN` (not `WEBZ_API_KEY`). Get an API key from the [Webz.io dashboard](https://webz.io).
</Note>

## Example Usage

Here's how to use the `WebzioNewsSearchTool` within a CrewAI agent:

```python
import os
from crewai import Agent, Task, Crew
from crewai_tools import WebzioNewsSearchTool

with WebzioNewsSearchTool(api_token=os.environ["WEBZ_API_TOKEN"]) as news_tool:
    researcher = Agent(
        role="Research Analyst",
        goal="Find recent news on any topic",
        backstory="Expert researcher with access to Webz.io news search.",
        tools=[news_tool],
        verbose=True,
    )

    research_task = Task(
        description="Find the top 3 recent breakthroughs in quantum computing.",
        expected_output="A summary of the top 3 breakthroughs with source URLs.",
        agent=researcher,
    )

    crew = Crew(agents=[researcher], tasks=[research_task], verbose=True)
    result = crew.kickoff()
    print(result)
```

Use the tool as a context manager (or call `stop()` when done) to shut down the MCP session.

## Configuration Options

The `WebzioNewsSearchTool` accepts the following parameters during initialization:

* `api_token` (str, optional): Your Webz API token. Falls back to the `WEBZ_API_TOKEN` environment variable if not provided.
* `mcp_url` (str, optional): Custom MCP server URL. Falls back to the `WEBZ_MCP_URL` environment variable, then `https://news-search-mcp.webz.io/mcp`.
* `connect_timeout` (int, optional): Connection timeout in seconds (default: `30`).

When calling the tool (or when an agent invokes it), filter parameters are loaded live from MCP `tools/list`. Common parameters include:

* `query` (str): **Required**. Natural-language search query.
* `k` (int, optional): Number of results (1–100, default 10).
* `days` (int, optional): Lookback window in days.
* `language` (list[str], optional): e.g. `["english"]`.
* `country` (list[str], optional): ISO-2 codes, e.g. `["US", "GB"]`.
* `sentiment` (str, optional): `positive`, `negative`, or `neutral`.
* `ticker` (list[str], optional): Stock symbols, e.g. `["NVDA"]`.
* `domain` / `exclude_domain` (list[str], optional): Restrict or exclude publishers.

For the full filter reference, see the [Webz MCP tool reference](https://docs.webz.io/docs/webz/news-search-api-mcp#tool-reference).

## Advanced Usage

For filtered news research, steer the agent in the task description:

```python
research_task = Task(
    description=(
        "Search Webz news for analyst reaction to Nvidia earnings. "
        "Use ticker NVDA, the last 7 days, English only, and limit to 5 results."
    ),
    expected_output="Headline, publisher, and URL for each article.",
    agent=researcher,
)
```

## Using Webz via MCP

You can also connect your agent to the hosted Webz MCP server directly:

```python
from crewai import Agent
from crewai.mcp import MCPServerHTTP

agent = Agent(
    role="Research Analyst",
    goal="Find and analyze news on the web",
    backstory="Expert researcher with access to Webz news search",
    mcps=[
        MCPServerHTTP(
            url="https://news-search-mcp.webz.io/mcp",
            headers={"Authorization": "Bearer YOUR_WEBZ_API_TOKEN"},
        ),
    ],
)
```

Get your API key from the [Webz.io dashboard](https://webz.io). For more on MCP in CrewAI, see the [MCP overview](/en/mcp/overview).

## Features

* **Natural-Language Search**: Ask questions in plain language, not keywords
* **Global Coverage**: Semantic search over Webz.io's worldwide news index
* **Rich Filters**: Language, country, date, sentiment, domain, ticker, and more
* **Live Schema**: New filters ship with the MCP server — no package update required
* **Token-Efficient Excerpts**: Focused article snippets with titles and URLs
